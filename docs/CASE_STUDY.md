# Project case study

## Problem

Sales practice often depends on another person being available to role-play.

## Solution

A repeatable loop of buyer simulation, evidence-linked feedback, and targeted retry.

## Implementation

React interface, FastAPI backend, MongoDB persistence, and separately configured AI/audio services.

## Key decision

Coaching is tied to transcript evidence; generated feedback is not a guarantee of real-world sales improvement.

## Verification

Build and provider verification notes distinguish live checks, mocked tests, and manual audio validation.

## Limitations

Provider credentials, email recovery configuration, and human microphone checks remain environment-dependent.

## Development approach

This portfolio includes AI-assisted implementation and review. The project documentation and commit history provide implementation context; this case study does not claim every line was written by hand.
